# ADR-008: Public ATS APIs behind a connector interface; Workday deferred

**Status:** Accepted (Phase 5)

## Context
Jobs must come from somewhere reliable and legal to automate. Scraping job sites
(LinkedIn, Indeed) is brittle and against their terms. Many tech companies host their
careers pages on an ATS that offers a public, unauthenticated JSON posting API.

## Decision
- Discovery uses only the public posting APIs of **Greenhouse, Lever and Ashby**, for
  company boards the owner chooses (`companies` table: `source` + `slug`). A static
  directory offers verified suggestions.
- Every provider implements `connectors/base.Connector`:
  - `discover_jobs(board)` returns `BoardFetch` (raw postings, pages, completeness)
  - `normalize_job(raw, board)` returns `NormalizedJob`
  - `validate_job(job)` returns a list of problems
  - `health_check(board)`
  - plus `board_info` and `careers_url`
- **No provider-specific logic exists outside its connector class.** `registry.py` maps
  each source to its class.
- All connectors share `connectors/http.HttpFetcher`:
  - timeouts and a streamed response size cap
  - retries with exponential backoff and jitter for timeouts, transport errors, 429 and
    5xx, honouring `Retry-After`
  - an unknown board (404) is never retried
  - a generic User-Agent
- Provider specifics:
  - Lever paginates (skip/limit) and falls back from the US to the EU region.
  - Greenhouse and Ashby return whole boards in one response. Greenhouse reports
    `complete=False` when `meta.total` exceeds what it returned.
- **Workday is deferred.** It has no single public API: each employer is a tenant
  (`<tenant>.wd<N>.myworkdayjobs.com/<site>`) behind an undocumented, rate-limited JSON
  endpoint. Its application flow (per-employer accounts, multi-step wizards) is the
  hardest automation target. See AI_CONTEXT.md, "Why Workday is deferred".

## Consequences
- Discovery is stable and cheap. CI uses realistic fixtures (`tests/fixtures/boards/`);
  live tests (`tests/live/`, weekly workflow) catch API drift.
- Coverage is limited to companies on these three platforms that the owner tracks.
- Adding a provider means one connector class, a registry entry and a migration
  extending the `companies.source` CHECK. A matching automation adapter goes in
  `automation/platforms/`.
