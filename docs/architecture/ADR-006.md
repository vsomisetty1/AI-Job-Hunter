# ADR-006: Deterministic first; Claude optional, cached and cost-tracked

**Status:** Accepted (Phase 4; cost model confirmed before Phase 5)

## Context
LLMs improve resume understanding and writing, but API calls cost money, can fail, and
receive personal data. The owner wants the Claude Pro subscription to be essentially the
only AI cost, and subscription credentials may not be used by third-party apps.

## Decision
- Every feature has a deterministic path that works with no API key: the resume parser
  (`parsing/`), the profile heuristics (Agent 1), and discovery and dedup (Phase 5).
- Claude is called only when configured (`ANTHROPIC_API_KEY`) and useful:
  - Agent 0 sends only weak sections' text, at most one call.
  - Agent 1 sends a PII-free JSON (no name, contact details or links).
- `llm/client.py`:
  - structured outputs (`messages.parse` into Pydantic)
  - SDK retries with backoff
  - one retry with a larger budget on `max_tokens`
  - server-side refusal fallback
  - errors mapped to configuration, temporary and permanent; callers degrade to the
    deterministic result on any of them
- `llm/cache.py` caches responses in Postgres, keyed by prompt name and version, model,
  effort, schema and rendered prompt. `llm/pricing.py` costs every call, and
  `agents/runs.py` records tokens and USD in `agent_runs`.
- Prompts are versioned modules in `llm/prompts/`. Resume text is delimited and treated
  as untrusted input.
- Subscription-quality AI (shortlist scoring, tailoring, cover letters) is planned as
  **Claude Code commands run by the owner**, using the app's API. Pro/Max OAuth is never
  wired into the app. Fully automatic AI runs only with an API key, ideally under a
  Console spend cap.

## Consequences
- The app runs at $0 by default; enabling the API is a cost/quality choice, not a
  requirement.
- Repeated inputs cost nothing (cache), and spend is auditable per run.
- Two code paths exist per AI feature (deterministic and Claude), and both must be
  tested. Tests use `tests/fakes.FakeAnthropic`, never the real API.
- Model names and prices need occasional updates (configurable models; manual price
  table).
